# 제스처 스펙: 선택 · 물체 회전 · 카메라 (feat/hand-voice)

> 원본 아이디어
> - 물체 회전: 손바닥 위에 뭔가 올려놓은 듯한 자세 → 손 회전각을 그대로 적용
>   - 변경 (테스트 결과): 받치기는 손목을 많이 꺾어야 해서 힘듦 → **움켜쥐기(편 손에서 공을 가볍게 감싸듯 살짝 굽힘)** 로 교체
> - 카메라: 엄지·검지·중지로 스와이프 → 카메라 이동, 왼손 엄지·검지·중지 → 카메라 회전

## 1. 제스처 맵

### 오른손 (그리기 손)
| 자세 | 엄지 | 검지 | 중지 | 약·새끼 | 동작 |
|---|---|---|---|---|---|
| 그리기/깊이 | 펴짐 | 펴짐 | 접힘 | 접힘 | 핀치 → 노드, 왼손 높이로 z |
| 선택 커서 | 접힘 | 펴짐 | 펴짐 | 접힘 | 커서 표시 → 주먹 쥐면 선택 확정 |
| 카메라 이동 | 펴짐 | 펴짐 | 펴짐 | 접힘 | 연속 드래그 → 팬 |
| 주먹 | 접힘 | 접힘 | 접힘 | 접힘 | 직전 자세가 선택 커서면 선택, 아니면 체인 끊기 |
| 움켜쥐기 | 살짝 굽힘 | 살짝 굽힘 | 살짝 굽힘 | 살짝 굽힘 | 선택된 구조물 1:1 회전 (클러치) |

### 왼손 (보조 손)
| 조건 | 동작 |
|---|---|
| 오른손이 그리기/깊이 자세 | 손목 높이 → z 레이어 (기존) |
| 왼손 엄지·검지·중지 펴짐 | 연속 드래그 → 카메라 회전(오빗) |

### 양손
| 조건 | 동작 |
|---|---|
| 양손 펴기(손바닥이 카메라를 향함) + 벌리기/모으기 | 줌 (기존) |

## 2. 판정 우선순위 (프레임마다 위에서부터)

1. 양손 펴기 → 줌. 움켜쥐기로 잡힌 손도 4손가락이 펴져 있으면 펼침으로 봄 → 양손이면 줌 우선, 줌 중엔 회전 안 함
2. 오른손 움켜쥐기 → 회전 (펼침보다 먼저 판정)
3. 오른손 주먹 → 선택 확정 / 체인 끊기
4. 오른손 자세(그리기 · 선택 · 팬) → **200ms 유지돼야 모드 전환**
5. 왼손: 깊이(오른손이 그리기 자세일 때) > 오빗

HUD에 현재 모드를 크게 표시: `그리기 · 깊이 · 선택 · 카메라 이동 · 카메라 회전 · 회전 · 줌`

## 3. 판정 방법 (전부 worldLandmarks, 미터 단위)

| 항목 | 방법 | 임계값 |
|---|---|---|
| 손가락 접힘 | 기존 `isCurled(tip, pip)` | — |
| 엄지 펴짐 | `dist(thumb_tip 4, pinky_mcp 17) / dist(wrist 0, middle_mcp 9)` (✌️에선 엄지가 약지 위로 접혀 새끼MCP에 가까워짐) | > 0.82 펴짐, < 0.74 접힘 (히스테리시스, 테스트 실측: ✌️ 0.70 · 3손가락 0.87) |
| 움켜쥐기 (가볍게 감싸 쥠) | 4손가락 안 접힘 + 곧음 s ≥ 0.7 (갈고리 배제) + **엄지 비율 t < 1.24** (엄지가 손바닥 쪽으로 들어옴) + 엄지끝↔검지끝 > 0.3 (핀치 배제) | 해제 s ≥ 0.62, t < 1.3. 실측: 움켜쥐기 s 0.94 · t 1.12~1.15 / 편 손 s 0.95 · t 1.32~1.37 → s로는 구분 불가, t로 구분 |
| 모드 전환 | 같은 자세가 연속 유지 | 200ms |

- 왼손/오른손은 기존처럼 **화면 위치**로 구분 (handedness 라벨 안 씀)

## 4. 선택 (구현됨)

1. ✌️ 200ms 유지 → 3D 커서가 **초록 링**으로 바뀜 (`HandCursorState.selecting`)
2. SceneCanvas `SelectionPicker`가 커서와 요소를 **화면에 투영해서** 픽셀 거리 40px 이내 가장 가까운 것을 찾음 → **노랑** 하이라이트
   - 깊이(z)가 아니라 "링이 물체 위에 보이는지"로 조준 → ✌️ 자세에선 왼손 깊이 조절이 없어도 선택 가능
   - 노드 > 빔 > 솔리드 순으로 약간 우선
3. 주먹 → 선택 확정(**초록** 하이라이트), 체인도 끊음. HUD 상태줄에 `선택: 다리 (노드 5 · 빔 4)`
   - stable 자세가 ✌️ → 주먹으로 바뀌고, 마지막 ✌️가 600ms 이내일 때만. 그 외 주먹은 체인 끊기만
   - 주먹 쥐는 동안 손끝이 움직여도 조준점 고정 (원시 자세가 ✌️가 아니게 된 순간의 커서 유지)
   - 커서가 구조물에서 벗어나도 600ms 동안은 그 구조물로 확정 (`HOVER_GRACE_MS`)
4. 해제: 이미 선택된 구조물을 다시 ✌️ → 주먹 (토글), 빈 공간에서 ✌️ → 주먹, 키보드 `Esc`
5. 선택 단위 (`src/services/selection.ts`)
   - 가리킨 요소의 `groupName`이 의미 있으면(예: "다리") 같은 그룹 전부
   - "스케치"는 손으로 그린 모든 요소가 공유 → 그룹 기준에서 제외, **빔으로 연결된 덩어리**만
   - 삭제·리셋으로 요소가 사라지면 선택에서 자동 제거 (`pruneSelection`)
6. 시뮬레이션 중엔 선택·하이라이트 안 함 (노드가 움직여서 위치가 어긋남)

## 5. 물체 회전 (구현됨: 움켜쥐기 + 축 잠금, 1:1 + 클러치)

| 손 동작 | 화면 축 | 손목 가동 범위 |
|---|---|---|
| 문고리 돌리듯 비틀기 | Y (세로) | ±90° |
| 팔은 두고 손목만 앞(카메라 쪽)·뒤로 숙이기 (고개 끄덕이듯) | X (가로) | ±60° |
| 화면 안에서 기울이기 | Z (깊이) | ±25° (팔 전체를 기울이면 더) |

- **잡기:** 움켜쥐기 200ms 유지 → 손 방향 `q0` 저장, App이 원본 좌표 저장 (`startSession`). 선택 없으면 전체
- **손 방향:** 손목·검지MCP·중지MCP·새끼MCP 4점으로 좌표계 → 손가락 모양과 무관 (`handQuat`)
  - MediaPipe world (x 영상 오른쪽, y 아래, z 사용자 쪽) → 사용자 기준 (−x, −y, +z). 두 축 반전 = 180° 회전이라 손 회전 방향 그대로
- **축 잠금:** `dq = q_now · q0⁻¹`의 X·Y·Z twist 각 중 가장 큰 게 12° 이상 + 두 번째의 1.8배 이상 → 그 축 고정. 이후 그 축 성분만 적용 (다른 축 흔들림 무시)
- **월드 축:** 잠긴 화면 축을 카메라 방향(`cameraGesture.cameraQuat`)으로 변환 → 가장 가까운 월드 X/Y/Z + 부호. 옆에서 보면 화면 X축 = 월드 −Z
- **안정화:** 손 쿼터니언 slerp EMA 0.35, 출력 각도 데드존 2°
- **놓기:** 움켜쥐기가 아닌 자세 200ms → 15° 스냅해서 확정 (`end`). 축 판정 전에 놓으면 변화 없음. 0°면 원위치
- **좌표:** 원본에 매번 적용 (오차 누적 없음). 90° 배수로 확정되면 0.25 그리드 재스냅, 아니면 소수 4자리
  - 바닥 아래로 내려가면 전체를 위로 올림. `isFixed`는 유지 (프리셋 다리의 공중 벽체 앵커 보존)
  - 솔리드는 위치 + `rotation`(Euler)도 같이 회전
- **HUD:** 모드 배지 `회전 · Y축 +45°` / `회전 · 축 판정 중`, 놓으면 힌트 `회전 확정: Y축 +45°`, 상태줄 `회전: 다리 Y축 +45°`
- **시뮬레이션 중 / TEST 중:** 회전 안 함
- 검증 (합성 손): Y 40° → [0, 40, 0] 잠금 Y / Y 40° + X 8° → Y 잠금 / Y 20° + X 15° → 대기 / 떨림 3~4° → 대기. 다리 Y+90° → 그리드 위 정렬

## 6. 카메라 (구현됨: 연속 드래그)

- **오른손 3손가락 → 팬:** "장면을 잡고 끄는" 느낌. 손을 웹캠 화면 폭만큼 옮기면 장면도 (타깃 거리 기준) 화면 폭만큼 이동
- **왼손 3손가락 → 오빗:** 손을 화면 폭만큼 = 180° 좌우, 높이만큼 = 120° 상하. 손을 오른쪽으로 → 구조물 앞면이 오른쪽으로. 상하는 지면 아래로 못 내려감 (기존 제한 유지)
- 기준점: 손바닥 중심(중지MCP 9), EMA 0.4, 데드존 0.004 (기준점이 데드존 거리를 유지하며 따라옴 → 천천히 움직여도 연속)
- 모드 진입할 때마다 기준점 리셋 → 자세 바꾸는 순간 카메라가 튀지 않음
- 경로: HandTracker `pushCameraPan/Orbit` → `cameraGesture` 버스 → SceneCanvas `CameraController`가 매 프레임 `consumeCameraDrag`
- 팬과 오빗 동시 가능. 줌 중엔 팬 안 함. TEST 중엔 이동량만 재고 카메라는 안 움직임

## 6-1. 제스처 테스트 (TEST 버튼, 12단계)

자세 단계(1초 유지): 그리기 · 선택 커서 · 카메라 이동 · 주먹 · 움켜쥐기 · 카메라 회전 · 줌
동작 단계(한 번 달성하면 통과): 선택 확정(✌️→주먹) · 카메라 이동 드래그(화면 15%) · Y축 회전(45°) · X축 회전(30°) · 카메라 회전 드래그(화면 15%)
- 테스트 중엔 노드 찍기·선택·회전·카메라가 실제로 적용되지 않음 (채점만)

## 7. 인터페이스 (App/SceneCanvas 담당자와 협의)

```ts
// HandTracker
interface Props {
  // 기존 ...
  /** ✌️ → 주먹: App이 SceneCanvas가 보고한 hover 구조물을 선택 (없으면 해제) — 구현됨 */
  onSelect?: () => void;
  /** 움켜쥐기 회전 (축 잠금): axis = 월드 축, deg = 잡은 순간 대비 누적 — 구현됨 */
  onObjectRotate?: (e: { phase: 'start' | 'update' | 'end'; axis: 'x' | 'y' | 'z' | null; deg: number }) => void;
  /** 정규화 화면 단위 프레임 간 이동량 */
  onCameraPan?: (dx: number, dy: number) => void;
  onCameraOrbit?: (dYawDeg: number, dPitchDeg: number) => void;
}
// HandCursorState.selecting: ✌️ 모드 (선택 커서) — 구현됨
// SceneCanvas: selection={{ hover, selected }}, onHoverSelection(sel) — 구현됨
```

- `onObjectRotate`는 **누적 회전**을 보냄: App은 `start` 때 원본 좌표를 저장하고 `update`마다 원본에 (axis, deg)를 적용 (오차 누적 없음)
- 60fps 콜백 → App setState 대신 ref/외부 store 권장 (`hand-tracker-notes.md` 3번)

## 9. 완료 기준

- 자세 3개(그리기 · 선택 · 팬)를 번갈아 5번씩 해도 오인식 0회
- 움켜쥐고 손목 90° 롤 → 구조물이 화면에서 같은 방향으로 90° 회전, 떨린 채 3초 유지해도 각도 변화 0
- 클러치 2번 → 180° 회전
- 오른손 드래그로 팬, 왼손 드래그로 오빗이 동시에 동작
